The Godot game engine is great for making general use case graphical user interfaces (GUI) for standalone tools and applications, that are not exclusively game user interfaces.

As a proof of concept, in 2020 I created [a clone of the Trello interface](https://alfredbaudisch.com/projects/open-source/godello/) with Godot – as of today, almost 3 years later, the repository was starred 599 times on GitHub, so it proved to be quite popular and something approved by the community.

A proof of concept is cool, but can it be used to create real applications? Yes! As a matter of fact, some really cool tools and applications are fully made with Godot. Find the list below.

Also, at the end of the article, I talk about my book about the subject, a course about making GUIs and more resources.

## The List of Applications

### RPG in a Box

[![](/media/wp-content/2023/04/GodotGUI-RPGInaBox-1024x576.png)](/media/wp-content/2023/04/GodotGUI-RPGInaBox.png)

Bring your stories and ideas to life! [RPG in a Box](https://zeromatrix.itch.io/rpginabox) lets you easily create grid-based, voxel-style games and other interactive experiences!

Did you know that the Godot Editor is made with the Godot engine GUI system? And RPG in a Box is made with the Godot Editor. So _RPG in a Box is a Game Engine made with a Game Engine (the Godot Editor), which is made with a Game Engine (the Godot Engine)._

### Material Maker

[![](/media/wp-content/2023/04/GodotGUI-MaterialMaker-1024x580.png)](/media/wp-content/2023/04/GodotGUI-MaterialMaker.png)

[Material Maker](https://rodzilla.itch.io/material-maker) is a procedural materials authoring and 3D model painting tool, based on the Godot Engine. Materials and brushes are defined as graphs where nodes create or transform textures, and can be exported for the Godot, Unity and Unreal game engines.

It’s like Adobe Substance Designer, but free and open-source made with Godot.

### PixelOver

[![](/media/wp-content/2023/04/GodotGUI-PixelOver-1024x576.jpg)](/media/wp-content/2023/04/GodotGUI-PixelOver.jpg)

[PixelOver](https://pixelover.io/) is a software to transform your arts to pixel arts as best as possible, animate in realtime with pixel perfect transformations, bones and key animation system.

### Union Bytes Painter

[![](/media/wp-content/2023/04/GodotGUI-UnionBytes-1024x555.png)](/media/wp-content/2023/04/GodotGUI-UnionBytes.png)

[Union Bytes Painter](https://unionbytes.itch.io/union-bytes-painter) allows the creation of 2D sprite and low res textures with color, normal, height, roughness, and metallic maps. Sprites and textures can be edited using multi-channel mode in the 2D or 3D space. It is similar to common applications such as Substance Painter. Basically, it’s a cheap Adobe Substance Painter alternative (around US$ 13), but focused on retro looking textures.

### HeavyPaint

[![](/media/wp-content/2023/04/GodotGUI-HeavyPaint-1024x519.png)](/media/wp-content/2023/04/GodotGUI-HeavyPaint.png)

[HeavyPaint](https://www.heavypaint.com/) is a simple yet secretly powerful painting app! Focus on pure colors and shapes with a streamlined interface. Ideal for plein air painting, color notes, sketches and studies.

### Veles

![](/media/wp-content/2023/05/GodotGUI-Veles-1024x549.png)

The free and [open source](https://github.com/LyffLyff/Veles) [music application](https://lyfflyff.itch.io/veles). Listen, Organize and Tag all of your favourite songs with this completely free and open source software.

### GridlessDB

[![](/media/wp-content/2023/04/GodotGUI-GridlessDB-1024x576.png)](/media/wp-content/2023/04/GodotGUI-GridlessDB.png)

Use [a powerful and intuitive editor](https://radmatt.itch.io/gridless) with a drag-and-drop interface to design, edit and visualize content for your games, like items, quests, characters, and anything else your project needs. Then export to a text file or Unity’s Scriptable Objects.

### Pixelorama

[![](/media/wp-content/2023/04/GodotGUI-Pixelorama-1024x576.png)](/media/wp-content/2023/04/GodotGUI-Pixelorama.png)

[Pixelorama](https://orama-interactive.itch.io/pixelorama) is a free and open source pixel art editor, proudly created with the Godot Engine, by Orama Interactive. Whether you want to make animated pixel art, game graphics, tiles and any kind of pixel art you want, Pixelorama has you covered with its variety of tools and features. Free to use for everyone, forever!

### Dialogue Designer

[![](/media/wp-content/2023/04/GodotGUI-DialogDesigner-1024x576.jpg)](/media/wp-content/2023/04/GodotGUI-DialogDesigner.jpg)

An easy to use but [powerful tool](https://radmatt.itch.io/dialogue-designer) for creating branching dialogues for games.

### Dungeondraft and Wonderdraft

![](/media/wp-content/2023/04/GodotGUI-Dungeondraft-1024x541.png)

Dungeondraft and Wonderdraft are brilliant and extensible tools for map making from the same creator – check [Dungeondraft](https://dungeondraft.net/) and [Wonderdraft](https://www.wonderdraft.net/) websites.

### Honorable Mentions

-   **[Grider](https://splitpainter.itch.io/grider): The Grid Creator**. Create, customize and export grids on top of reference images, for drawing guidance, a tool for artists and those learning how to draw. This is my second Godot project ever, from May/2019. It’s very barebones, but it’s when I got in love with Godot for GUI (and it’s [open-source](https://github.com/alfredbaudisch/grider)).
